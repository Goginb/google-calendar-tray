# Google Calendar Tray

Небольшое Windows-приложение, которое живёт в системном трее и открывает компактную повестку по клику. Поддерживает:

- события на сегодня и на текущую неделю;
- часовая сетка со шкалой слева: высота встречи показывает её длительность, неделя отображается в семи колонках, пересекающиеся встречи располагаются рядом;
- перенос встречи мышью по времени и между днями, изменение длительности перетягиванием нижнего края;
- одновременный показ нескольких Google-календарей;
- быстрые переключатели видимых календарей на главной странице;
- создание событий с выбором любого календаря с правом записи, включая скрытые на главной;
- гостей встреч и локальную адресную книгу: добавление контактов вручную, выбор по имени или почте и автоматическое сохранение гостей после создания или изменения события;
- редактирование и удаление событий в календарях с правом записи;
- перенос события на другую дату и время через меню по правому клику с сохранением длительности;
- подтверждение удаления и предупреждение о несохранённых изменениях;
- личный архив выполненных событий с возможностью просмотра и восстановления;
- безопасный OAuth-вход через системный браузер;
- локальное хранение настроек и шифрование OAuth-токенов средствами Windows (Electron `safeStorage`).

## Установка для Windows

Скачайте установщик `Google Calendar Tray Setup <версия>.exe` из [последнего релиза](https://github.com/Goginb/google-calendar-tray/releases/latest) и запустите его. После установки импортируйте свой OAuth JSON и войдите через Google — настройка описана ниже.

## Быстрый запуск из исходников

Требуется Node.js 20 или новее.

```powershell
npm install
npm start
```

После запуска приложение остаётся в системном трее и не открывает окно само. Обычный клик показывает или скрывает окно, двойной клик открывает Google Calendar в браузере, правый клик открывает меню. Кнопка `×` только скрывает окно; полностью закрыть программу можно через пункт **Выход** в меню трея.

Окно календаря расширено до 940 × 820 и его можно менять по размеру. Слева закреплена часовая шкала; сетка прокручивается на все 24 часа. В режиме **Неделя** каждый день занимает отдельную колонку. События на весь день находятся над часовой сеткой, а встречи через полночь видны в каждом затронутом дне. Красная линия отмечает текущее время.

События с непустым описанием выделены золотистой рамкой и значком `✎` перед названием. Выделение видно также у коротких встреч, в режиме **Неделя** и у событий на весь день; цвет календаря сохраняется.

Чтобы перенести встречу, потяните её карточку вверх или вниз; в режиме **Неделя** можно также перенести её в соседний день. Чтобы изменить длительность, потяните нижний край карточки. Шаг изменения — 15 минут; при изменении окончания минимальная длительность составляет 15 минут. Новое время видно до отпускания мыши. После отпускания оно сохраняется в Google Calendar, а при ошибке исходное время остаётся прежним. **Escape** отменяет перетаскивание. События в календарях только для чтения менять нельзя. С клавиатуры **Alt + стрелки** переносят встречу, а стрелки **↑ / ↓** на нижнем крае меняют окончание. Обычный клик по карточке открывает полную форму редактирования.

На главной странице раскройте блок **Календари** и отметьте календари, события которых нужно видеть. Блок можно свернуть обратно. Эти галочки не ограничивают выбор календаря при создании события: в форме нового события доступны все календари с правом записи. Нажмите на событие, чтобы изменить его или удалить. Нажмите на него правой кнопкой мыши и выберите **Перенести на…**, чтобы выбрать новую дату и время. Длительность сохранится; для события на весь день выбирается только дата. Когда вы меняете время начала в полной форме, время окончания при необходимости сдвигается вперёд. Время окончания можно затем выбрать свободно; если оно окажется раньше начала, форма покажет ошибку при сохранении. Удаление требует подтверждения; при переходе из формы с несохранёнными изменениями приложение также спросит подтверждение.

В поле **Гости** начните вводить имя или почту: подходящие контакты появятся сразу под строкой. Выберите человека кликом или клавишей Enter. Если введена новая почта, появится пункт её добавления: приложение предложит имя из адреса вида `name.surname@example.com`, а вы сможете исправить его перед сохранением. Если имя нельзя надёжно прочитать из адреса, поле останется пустым. Полный список открывается кнопкой **Все контакты** рядом с полем или кнопкой `▤` вверху окна. В нём можно найти контакт, изменить имя или удалить запись. Новых гостей приложение также запоминает после успешного сохранения встречи. Контакты остаются локально после выхода из Google-аккаунта. При добавлении гостей Google Calendar отправляет им приглашения и обновления.

В установщик включены 57 сотрудников из вкладки **Лист1** [таблицы контактов](https://docs.google.com/spreadsheets/d/16lTB2pRO7E25Wqk-9Wri-VBM3tcgGLzSZDXj4Z8fG80/edit?gid=898074540) по состоянию на 30.09.2026. Контакт Игоря Огибина подписан в порядке «имя фамилия» по уточнению пользователя. При первом запуске новой версии сотрудники добавляются в локальную книгу. Уже сохранённые имена и личные контакты сохраняются; удалённые вручную контакты не появляются снова после перезапуска. Изменения в исходной таблице не обновляют уже собранную программу автоматически.

Стрелки рядом с датой перелистывают дни в режиме **Сегодня** и недели в режиме **Неделя**. Кнопка **К сегодня** находится под датой и возвращает текущий период. Новое событие по умолчанию открывается на выбранную дату.

Кнопка `✓` рядом с событием сразу отмечает его выполненным. По умолчанию оно исчезает с сетки и остаётся в разделе **Выполнено**. Галочка **Показать все события** возвращает выполненные встречи на сетку выбранного дня или недели: они показаны приглушённым цветом, с зачёркнутым названием и отметкой `✓`. Кнопка `↶` на каждой такой карточке снимает отметку только с этого события и возвращает его в обычный календарь; после возврата снова доступны перенос и изменение длительности. События на весь день тоже можно вернуть по отдельности. Режим показа сохраняется после перезапуска и учитывает выбранные календари.

Счётчик и список в разделе **Выполнено** показывают события выбранного дня, а в режиме **Неделя** — выбранной недели. Чтобы увидеть старые выполненные события, перейдите к нужной дате стрелками. Кнопка **Вернуть в общий список** также снимает отметку. Архив действует только в этом приложении и не меняет события в Google Calendar.

Если Windows прячет новые значки, нажмите стрелку `^` рядом с часами и перетащите значок календаря в видимую часть трея. Приложение теперь использует настоящий Windows ICO-ресурс, а не SVG.

## Подключение Google OAuth

Реальные OAuth-секреты намеренно не входят в проект. Их нужно создать один раз для своего аккаунта:

1. Откройте [Google Cloud Console](https://console.cloud.google.com/) и создайте или выберите проект.
2. В разделе **APIs & Services → Library** включите **Google Calendar API**.
3. В **OAuth consent screen** настройте экран согласия. Если приложение в режиме Testing, добавьте свой Google-аккаунт в **Test users**.
4. В **Credentials → Create credentials → OAuth client ID** выберите тип **Desktop app**.
5. Скачайте JSON-файл клиента.
6. В приложении откройте настройки, нажмите **Импортировать JSON**, выберите скачанный файл, затем **Войти через Google**.

Приложение копирует credentials в пользовательский профиль приложения, а не в репозиторий. Для разработки также можно положить файл под именем `credentials.json` в корень проекта или задать полный путь переменной окружения `GOOGLE_CALENDAR_CREDENTIALS`. `credentials.json` добавлен в `.gitignore`.

Google покажет предупреждение для приложения в режиме Testing — это ожидаемо для личного OAuth-клиента. OAuth использует временный loopback-адрес `127.0.0.1`; открывать входящие порты в брандмауэре не требуется.

## Сборка Windows

Собрать распакованную версию:

```powershell
npm run pack
```

Собрать установщик NSIS:

```powershell
npm run dist
```

Результат появится в папке `dist`. Установочный файл `Google Calendar Tray Setup <версия>.exe` можно передать другому пользователю Windows. При установке и обновлении создаётся ярлык на рабочем столе, а также ярлык в меню «Пуск». Для входа в Google текущая версия по-прежнему требует OAuth JSON; этот файл не включается в установщик.

Иконки приложения генерируются локально командой `npm run icons`; в репозитории хранится только воспроизводимый скрипт, а бинарные `build/icon.*` игнорируются.

## Где хранятся данные

Настройки, личный архив (`archive.json`), адресная книга (`contacts.json`), импортированный OAuth JSON и зашифрованные токены находятся в `%APPDATA%\google-calendar-tray`. Удаление этих файлов сбрасывает локальную настройку, архив и контакты. Кнопка **Выйти** удаляет сохранённые токены, но не отзывает доступ на стороне Google; при необходимости отозвать его можно в настройках безопасности Google-аккаунта.

## Проверки

```powershell
npm test
npm run smoke
npm run smoke:timeline
```

Unit-тесты проверяют недельный диапазон, формирование данных событий, фильтрацию выполненных по дате, права записи и сохранение личного архива. Smoke-тест запускает Electron, подключается к локальному renderer через временный DevTools-порт, проверяет выбор календаря, подтверждение удаления, дневной счётчик, архивирование и восстановление, затем завершает тестовый процесс.

Проверка `smoke:timeline` использует реальный интерфейс и изолированный тестовый календарь. Она проверяет пропорции карточек, пересечения, перетаскивание мышью, изменение длительности, отмену, ошибку сохранения и закрепление шкалы при прокрутке. Настоящие события Google при этой проверке не изменяются.
