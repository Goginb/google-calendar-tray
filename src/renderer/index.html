Зачем нужен JSON?

Google не даёт календарным приложениям доступ к аккаунту без OAuth-клиента. Это одноразовая настройка, а не файл с вашими событиями или паролем.

  1. Включите Google Calendar API в своём проекте Google Cloud.
  2. Создайте OAuth Client ID типа Desktop app.
  3. Скачайте JSON и импортируйте его кнопкой ниже.
  4. Нажмите «Войти через Google».
